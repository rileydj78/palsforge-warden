Game settings

Some settings aren't in effect

    Start from a preset

    Fills in the form below; nothing changes until you review and apply.

    Import takes a file exported here or any PalWorldSettings.ini (from another server or a settings generator). Passwords are never exported or imported.

    Other options

    Options Warden doesn't explain yet. They're kept exactly as they are.

    Engine.ini (advanced)

    Unreal Engine tuning, such as the network tick rate. Written at the next stop, with a copy of the old file kept. Wrong values can make the server lag or not start, so change one thing at a time.

    Mods

    Turning a mod off moves it to Warden's own folder; nothing is deleted.

    Install a mod

    ModKindSizeChangedStateActions

    Most mods must also be installed, at the same version, on every player's game.
